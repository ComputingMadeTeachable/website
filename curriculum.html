How our units map to the KS3 curriculum.

Unit 1 in each year builds the problem-solving foundation that everything else rests on: computational thinking and algorithm design. Later units will cover the rest of the programme of study, and this page grows as they're released.

Year 7 · Unit 1 · 7 lessons

Problem Solving and Design

Computational thinking and algorithm design

Students learn to think like problem solvers: breaking problems down, spotting patterns and writing instructions so clear that a robot can follow them. Everything is unplugged, so no computers or software are needed.

Lessons

  1. 1Think Like Problem Solvers: decomposition and pattern recognition
  2. 2–3Algorithm Design: Write It Clearly and Program the Robot
  3. 4–5Robot Delivery Mission: plan, write, test and debug a robot program
  4. 6–7Revision and End of Unit Test (35 marks), then feedback

National Curriculum coverage

  • Introduced Computational abstractions. Robot grids and a school map model real places as squares, and a trace table records the robot's position and direction after each line. Abstraction is named and taught as a skill in Year 8.
  • Partial Key algorithms and logical reasoning. Students compare clear and unclear instructions, shorten a program with MOVE FORWARD (number), and use logical reasoning to find the line with the bug. Sorting and searching come in later units.
  • Introduced Programming and data structures. Exact robot commands in sequence, and data in tables (a Sports Day timetable and trace tables). No programming language is used in this unit.

Year 8 · Unit 1 · 13 lessons

Problem Solving and Design

Computational thinking and algorithm design

Students use all four computational thinking skills, then design algorithms three ways: structured English, flowcharts and pseudocode, with decisions and loops. The unit ends with Robo's Rescue Mission, a three-lesson design project.

Lessons

  1. 1Computational Thinking in Everyday Life
  2. 2Computational Thinking in Computing
  3. 3Structured English
  4. 4Flowcharts: Sequences
  5. 5Flowcharts: Decisions and loops
  6. 6Pseudocode: Sequence
  7. 7Pseudocode: Decisions and loops (IF … ELSE, WHILE)
  8. 8–10Robo's Rescue Mission: plan, build, test, debug and share
  9. 11–13Revision, End of Unit Test (45 marks) and a feedback lesson

National Curriculum coverage

  • Strong Computational abstractions. A busy picture becomes a grid model; robot grids model rooms, walls, doors and keys in every algorithm lesson; trace tables record the robot's state after each step.
  • Partial Key algorithms and logical reasoning. Students compare 16 separate steps with a REPEAT loop, and a WHILE loop with a fixed distance, then find and fix errors in flowcharts and pseudocode. Sorting and searching come in later units.
  • Introduced Programming and data structures. Sequence, selection (IF … ELSE) and iteration (REPEAT, WHILE) in pseudocode with exact keywords and indentation: the foundations for a textual language. No programming language is used in this unit.

Problem Solving and Design

Algorithms in pseudocode

Students move from robot commands to the pseudocode used in Cambridge IGCSE, starting with variables, input and output. The first lesson is ready, and more lessons are on the way.
